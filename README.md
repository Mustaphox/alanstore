# ALAN Store 🛍️

متجر "الآن" (ALAN) هو منصة تجارة إلكترونية متخصصة في بيع العبايات الفاخرة والمميزة. 
تم بناء هذا المشروع ليكون سريعاً، متجاوباً بالكامل، ومُحسناً للاستضافة المشتركة (مثل InfinityFree).

## المميزات ✨
- واجهة مستخدم (UI) عصرية وجذابة تدعم الوضع الفاخر (Luxury Mode).
- متجاوب 100% مع الهواتف الذكية والأجهزة اللوحية (Responsive).
- نظام سلة مشتريات (Cart) متكامل ومفضلات (Wishlist).
- عملية إتمام الطلب (Checkout) سريعة بخطوة واحدة مع حساب تلقائي لتكاليف التوصيل حسب الولاية والبلدية.
- لوحة تحكم لإدارة المنتجات، الطلبات، والعملاء.
- لا يتطلب إطار عمل معقد، مبني باستخدام Vanilla PHP و JavaScript.
- مُحسّن للعمل على الاستضافات المجانية بدون مشاكل.

## التنصيب 🛠️
1. قم برفع جميع ملفات المشروع إلى مجلد `htdocs` أو `public_html` في استضافتك.
2. قم بإنشاء قاعدة بيانات MySQL في لوحة تحكم الاستضافة (cPanel).
3. استورد ملف قاعدة البيانات المرفق `alan_store_hosting.sql` باستخدام `phpMyAdmin`.
4. افتح ملف `config.php` وقم بتحديث بيانات الاتصال بقاعدة البيانات الخاصة بك.
5. استمتع بمتجرك!
