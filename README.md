## ✨ أبرز المميزات الاستثنائية

### 1. مساعد الدعم الذكي (ALAN AI Assistant) 🤖
نظام ذكاء اصطناعي متقدم مدمج مباشرة في المتجر يعمل كمستشارة أناقة شخصية وخدمة عملاء فورية:
- **نظام هجين ذكي (Hybrid Engine)**:
  - دعم كامل لـ **Google Gemini 1.5 Flash API** لفهم سياق العميل وتقديم إجابات مخصصة وذكية.
  - محرك محلي بديل فوري (Built-in Expert Engine) يعمل حتى بدون مفتاح API، يفهم اللهجة الجزائرية والأسئلة الشائعة حول العبايات، التوصيل، والمقاسات.
- **عرض المنتجات التفاعلي داخل الشات (Interactive Product Showcase)**:
  - عند طلب العميل عرض المنتجات أو السؤال عن العبايات الأكثر طلباً، يقوم المساعد بعرض بطاقات منتجات تفاعلية داخل فقاعة المحادثة بصورة المنتج، اسمه، خامته، سعره بالدينار الجزائري، وزر مباشر للطلب.
- **شريط الوصول السريع الدائم (Quick Actions Bar)**:
  - أزرار سريعة فوق حقل الكتابة تتيح للعميل استعراض العبايات، معرفة المقاسات، أسعار التوصيل، والتواصل الفوري دون الحاجة للكتابة.
- **تكامل زر واتساب الفوري**:
  - تحويل تلقائي لأي اقتراح واتساب في المحادثة إلى زر أخضر بارز وواضح ينقل الزبونة إلى محادثة واتساب برقم المتجر الرسمي.

### 2. السرعة الفائقة والأداء المتقن (Ultra-Fast Performance) ⚡
- **ضغط الوسائط المتعددة**:
  - ضغط شعار الموقع من 1.5 ميجابايت إلى 47 كيلوبايت مع نسخة WebP خفيفة للغاية (4.9 كيلوبايت) بتقنية `<picture>` التكيفية.
- **ضغط خادم Apache عبر .htaccess**:
  - تفعيل ضغط `mod_deflate / Gzip` للنصوص، ملفات CSS، JavaScript، وJSON.
  - تفعيل التخزين المؤقت للمتصفح `ExpiresByType` و `Cache-Control` (سنة كاملة للصور والخطوط، شهر لملفات التنسيق).
- **فهرسة مركبة لقاعدة البيانات (MySQL Indexes)**:
  - إضافة فهارس مركبة ذكية (`idx_status_featured_created`, `idx_status_category`, `idx_status_is_new`, `idx_status_price`) لتسريع استعلامات تصفح العبايات بمعدل أسرع بـ 10 أضعاف.
- **كاش ديناميكي للملفات (Cache Busting)**:
  - استخدام `filemtime` لتحديث ملفات CSS/JS تلقائياً لدى الزوار فقط عند تعديلها دون الحاجة لطلب مسح الكاش يدوياً.

### 3. تجربة تسوق الهاتف المتجاوبة (100% Mobile First) 📱
- **بطاقات منتجات متناسقة وموحدة (Uniform Grid Cards)**:
  - تثبيت نسبة العرض للارتفاع `3:4 Aspect Ratio` للصور مع تجنب أي تشوه أو اختلاف في الارتفاع.
  - تحديد دقيق لارتفاع عناوين المنتجات بسطرين متناسقين (`height: 2.76em`) مع تثبيت صف السعر والشراء بالأسفل دائماً.
- **فوتر مخصص للهواتف بدون أي تداخل**:
  - هيكلة شبكية محسنة بنسبة 2 أعمدة على الهواتف مع عزل تام للهيدر وتثبيت تدفق الشعار لمنع أي تداخل مع النصوص.
  - مسافة أمان سفلية (`padding-bottom: 105px`) تمنع تغطية الأزرار العائمة (واتساب والذكاء الاصطناعي) لروابط الفوتر وحقوق الملكية.

### 4. حساب تلقائي للشحن والدفع عند الاستلام (58 ولاية) 🚚
- **تغطية شاملة لـ 58 ولاية جزائرية**:
  - جلب فوري للبلديات وأسعار التوصيل (للمنزل أو المكتب) بمجرد اختيار الولاية عبر AJAX (`api/shipping.php`).
- **إتمام الطلب بخطوة واحدة (1-Step Checkout)**:
  - تجربة شراء فائقة السلاسة مخصصة لسلوك الشراء المحلي في الجزائر (Cash On Delivery).
- **إشعارات الشراء التفاعلية (FOMO Social Proof Popups)**:
  - ظهور تنبيهات ذكية وغير مزعجة تحفز الزوار بالشراء الأخير الذي تم في مختلف الولايات.
- **تذكير السلة المتروكة (Cart Abandonment Reminder)**:
  - تنبيه أنيق يذكر الزبونة بالمنتجات الموجودة في سلتها لإتمام الطلب.

### 5. لوحة تحكم إدارية متكاملة (Comprehensive Admin Panel) 📊
- **إدارة دورة حياة الطلبات**:
  - استعراض تفصيلي للطلبات، المنتجات، العناوين، وتغيير الحالة مع سجل زمني (Timeline).
  - زر **تأكيد عبر واتساب** يقوم بإنشاء رسالة واتساب جاهزة باسم الزبونة وتفاصيل طلبيتها ورابط تأكيد الشحن بنقرة واحدة.
- **نظام كشف الاحتيال والمخاطر (Risk & Fraud Scoring)**:
  - فحص عناوين IP، تكرار الطلبات، وسجل العملاء للحد من الطلبات الوهمية.
- **إدارة الوسائط ومعرض الصور**:
  - إمكانية إضافة عدة صور لكل عباية، مع دعم الرفع المباشر أو الروابط الخارجية وتحديد الصورة الرئيسية.
- **إدارة كوبونات الخصم (Promo Codes)**:
  - إنشاء كوبونات بنسبة مئوية أو قيمة ثابتة مع تاريخ انتهاء وحد أقصى للاستخدام.
- **تتبع وتحليلات Meta Pixel & TikTok Pixel**:
  - دعم تتبع إعلانات فيسبوك وتيك توك مع Conversion API (CAPI) لحساب مبيعات الإعلانات بدقة متناهية.

### 6. الأمان والموثوقية (Enterprise Grade Security) 🛡️
- **حماية CSRF**: توكنات مشفرة عشوائياً لكل جلسة لمنع الهجمات الموجهة.
- **حماية من حقن SQL**: استخدام كامل لـ PDO مع Prepared Statements والمعاملات (Transactions).
- **الحد من معدل الطلبات (Rate Limiting)**: حماية مسارات الشات والطلبات ونماذج الاتصال من السبام والفيض.
- **حماية الملفات الحساسة**: حظر الوصول لملفات `.sql`, `config.php`, والمستندات الداخلية عبر `.htaccess`.

## 🚀 دليل التثبيت والتشغيل المحلي (Local Installation)

### المتطلبات الأساسية
- خادم محلي: **XAMPP**, **Laragon**, أو **WAMP** يدعم **PHP 7.4** أو **PHP 8.x**.
- قاعدة بيانات **MySQL 5.7+** أو **MariaDB**.
- متصفح ويب حديث.

### خطوات التثبيت:
1. **استنساخ المستودع (Clone Repository)**:
   ```bash
   git clone https://github.com/Mustaphox/alanstore.git "c:/xampp/htdocs/alan store"
   ```
2. **إنشاء قاعدة البيانات**:
   - افتح **phpMyAdmin** (`http://localhost/phpmyadmin`).
   - أنشئ قاعدة بيانات جديدة باسم: `if0_42600030_alaan` (أو أي اسم تفضله).
   - قم باستيراد ملف: `alan_store_hosting.sql`.
3. **ضبط إعدادات الاتصال**:
   - افتح ملف `config.php` في محرر الأكواد:
   ```php
   const DB_HOST    = 'localhost';
   const DB_NAME    = 'if0_42600030_alaan'; // اسم قاعدة بياناتك
   const DB_USER    = 'root';
   const DB_PASS    = '';
   const APP_URL    = '/alan store'; // مسار المجلد على السيرفر
   ```
4. **فتح المتجر**:
   - افتح المتصفح على: `http://localhost/alan%20store/`
   - للدخول إلى لوحة التحكم: `http://localhost/alan%20store/admin/`

## 🌐 النشر على الاستضافات السحابية والمشتركة (Production Deployment)

تمت تهيئة المتجر ليعمل بنسبة 100% وبأقصى سرعة على كافة الاستضافات المشتركة والسحابية (cPanel, Hostinger, InfinityFree, Namecheap):

1. قم برفع جميع ملفات المشروع إلى مجلد `public_html` أو `htdocs`.
2. من لوحة تحكم الاستضافة (cPanel)، أنشئ قاعدة بيانات ومستخدماً جديداً وامنحه كافة الصلاحيات.
3. استورد ملف `alan_store_hosting.sql` عبر **phpMyAdmin**.
4. عدل ملف `config.php` ببيانات الاتصال الجديدة:
   ```php
   const DB_HOST    = 'localhost'; // أو عنوان خادم MySQL في استضافتك
   const DB_NAME    = 'your_db_name';
   const DB_USER    = 'your_db_user';
   const DB_PASS    = 'your_strong_password';
   const APP_URL    = ''; // اتركه فارغاً للتعرف التلقائي
   ```
5. تأكد من عمل ملف `.htaccess` لإخفاء امتداد `.php` من الروابط وتفعيل ضغط Gzip.

## ⚙️ إعدادات المتجر والتخصيص (Configuration)

يمكنك ضبط كافة إعدادات المتجر بسهولة عبر لوحة التحكم (`admin/settings.php`):
- **اسم المتجر والوصف**: للظهور في محركات البحث (SEO).
- **رقم الواتساب الرسمي**: لإعادة توجيه الاستفسارات وزر الواتساب العائم ومراسلة الطلبات.
- **تفعيل أو تعطيل الذكاء الاصطناعي**: خيار بضغطة زر لتشغيل أو إيقاف المساعد الذكي.
- **مفتاح Google Gemini API Key**: أضف مفتاحك الخاص لتفعيل قدرات Gemini المتقدمة.
- **رسالة الترحيب واسم المساعد**: تخصيص اسم المساعد ورسالته الترحيبية للزبائن.
- **أكواد التتبع**: Meta Pixel ID و TikTok Pixel ID لحملاتك الإعلانية.
